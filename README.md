# DSC101 – Design and Analysis of Algorithms

This repository contains the practical assignments and course project for  
**DSC101 – Design and Analysis of Algorithms**, focusing on exact,
approximation, and heuristic algorithms implemented and analyzed using
Jupyter Notebooks.

---

## Repository Structure

- `prac1/` – Brute force algorithm for the Vertex Cover problem  
- `prac2/` – Greedy 2-approximation algorithm for Vertex Cover  
- `prac3/` – Comparison of brute force and greedy algorithms  
- `prac4/` – LP-rounding based 2-approximation for Vertex Cover  
- `prac5/` – K-centre problem on real datasets  
- `project/` – Course project on K-Means clustering  

---

## Practicals

1. Brute force implementation of the Vertex Cover problem with time and size analysis.  
2. Greedy 2-approximation algorithm for Vertex Cover and approximation factor computation.  
3. Comparison of brute force and greedy algorithms for fixed `n = 20`.  
4. LP-rounding based 2-approximation for the Vertex Cover problem.  
5. K-centre problem using heuristic and greedy approximation algorithms.

---

## Course Project: K-Means Clustering

### Project Overview
This project focuses on implementing and analyzing the **K-Means clustering**
algorithm on synthetic and real datasets, with an emphasis on performance and
result interpretation.

---

## How to Run

- Open Jupyter Notebook  
- Navigate to the required practical or project folder  
- Open the `.ipynb` file and run the cells
